Protocole de fermeture de session :

1. **Vérifier IMPLEMENTATION.md** : tous les livrables terminés dans cette session sont-ils cochés `[x]` ? Sinon, demander confirmation et cocher.
2. **Mettre à jour STATE.md** : Maintenant (dernière action, prochaine action, bloquants) + Phase en cours (progression chiffrée).
3. **Ajouter une ligne dans JOURNAL.md** : `{YYYY-MM-DD HH:MM} — {objectif session} — {ce qui a été fait} — {ce qui reste}`
4. **Si décision archi prise pendant la session** : ajouter une ligne dans DECISIONS.md.
5. **Produire un récap session prêt à coller dans Claude Chat** :
   - Objectif initial
   - Livrables produits (avec chemins)
   - Décisions
   - Suite recommandée
6. **Rappeler** : "Côté chat, lance /chat-recap puis /memory-update pour synchroniser la mémoire."

Pas de modification de code ici, juste fermeture propre.
